Индивидуальное задание KrasevPS
Диапазон строк: 1114-1119

1. Создайте директорию с именем любимой автомобильной марки, в ней создайте директории с названиями основных моделей этой марки.
2. В каждой директории посвященной модели создайте файл info.txt, содержащий на отдельных строках полное название модели, год выпуска, тип кузова, мощность и краткую характеристику.
3. В корневой директории создайте файл, содержащий сообщение об ошибке выполнения команды git
4. С помощью команд pwd, cat, head, tail создайте из любого файла info.txt новый файл info_path.txt, содержащий на 1ой строке полный путь до текущего каталога
5. Перейдите в директорию os-labs/students-2026 из Лабораторной Работы №1 и загрузите из репозитория последнюю версию. В ней находится множество файлов с информацией о студентах с ожидаемым форматом названия: ФамилияИО
Выведите в терминал имена (первые строки txt файлов) всех студентов, содержащих в фамилии букву b, и отчество которых не начинается на A.
